FLOWCART AI — E-COMMERCE AUTOMATION DEMO

This is a static interactive portfolio prototype.
Open index.html in a browser to test the sample workflow.

GitHub Pages:
1. Upload index.html to the root of your repository.
2. Commit changes.
3. Open Settings > Pages.
4. Choose Deploy from a branch, branch main, folder /(root), then Save.

Limitations:
This does not connect to a real AI model, database, payment system, SMS/email, courier API or verified OTP provider. Inventory and events are sample data held in the browser. Real deployment requires a secure backend, database, authentication, API integrations, privacy controls and audit logs. Do not publish API keys or private customer data.
